## Description

Identifies adult patients with heart failure with reduced ejection fraction (HFrEF), defined as a left ventricular ejection fraction (LVEF) less than 40% documented on echocardiography, with a confirmed ICD-10 diagnosis of heart failure. Derived from the OMOP Common Data Model using standard concept identifiers. Intended for use in trial-ready cohort identification and cardiovascular outcomes research.

## Inclusion Criteria

Age >= 18 at index date; ICD-10-CM code I50.x (heart failure) in condition_occurrence; LVEF < 40% documented in measurement domain (LOINC 18009-2 or 8806-2); Echocardiogram within 24 months prior to index date; At least one encounter in the 12 months prior to index date.

## Exclusion Criteria

Age < 18; No qualifying echocardiogram within 24 months; LVEF >= 40% on most recent echocardiogram; Heart failure diagnosis in setting of acute MI only (I21.x as primary diagnosis with no subsequent heart failure encounter); Enrollment in hospice or palliative care at index date.
